# Night Desk: Reborn — playable prototype

A from-scratch browser superhero dispatching game. Open `index.html` in a browser or deploy the folder using GitHub Pages. No build step, dependencies, or server required. Google Fonts are optional.

Features: original procedural isometric city renderer with extruded building geometry and camera pan/zoom; incident spawning and deadlines; 6 original heroes; four skill stats; multi-hero dispatch and success calculations; fatigue and recovery; cooldowns; XP/leveling; credits, reputation, shifts; pause/speed controls; responsive phone layout.

This is an original foundation/prototype, not yet a feature-complete recreation of any other game. The renderer is custom Canvas 2D isometric geometry (2.5D), not a hardware-accelerated 3D engine.
